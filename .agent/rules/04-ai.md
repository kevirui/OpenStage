# AI Rules

Gemini is the initial speech/translation provider.

## Provider isolation

Gemini-specific implementation must live inside the AI/provider layer.

Do not couple domain models to Gemini response formats.

## Streaming

Prefer streaming/incremental processing when supported.

The system should eventually produce partial and/or final caption events.

## Translation

The MVP requires:

```text
English → Spanish
```

Do not implement additional languages until the required flow works reliably.

## Context

When useful, the system may provide technical glossary information to improve recognition and translation.

Keep glossary functionality simple.

A JSON configuration is sufficient for the MVP.

## Reliability

AI failures must be handled gracefully.

Possible states:

```text
CONNECTING
CONNECTED
RECONNECTING
ERROR
```

Do not allow a provider failure to crash unrelated sessions.

## Prompt design

AI prompts should be centralized and versioned in the codebase.

Do not scatter large prompt strings throughout the application.
